Entropy Lab

In 1948 Claude Shannon defined a number for how impure a set of outcomes is — the fewer bits you'd need, on average, to describe an outcome drawn from it. Decision trees use this number, entropy, to decide which question to ask first. Drag the slider below to build a feel for its shape.

1. How impure is a set?

A set with everything the same class is perfectly pure — zero entropy. A 50/50 split is the most impure a two-class set can be. Move the slider to change the mix of Class A (circles) and Class B (stars) among 50 points, and watch the curve, the scatter plot, and the number move together. The dashed line is the best single split of the plot — and it can never gain more than the set's entropy.

How a threshold is found: sort the column. Between every pair of neighbouring values there is a possible cut; since no row sits between two neighbours, any number in that gap makes the same split, so we label the cut with the midpoint (43 and 52 → 47.5). Only cuts where the class flips need testing — a cut between two same-class neighbours can't beat one at a class change. Each cut sends rows to “≤” or “>”, and the cut with the highest Information Gain represents the column. The “43|52” tags below show which two neighbours each cut sits between.
